현재 테스트 상태:
!`python -m pytest tests/ -q --tb=line --no-header 2>&1 | tail -20`

위 결과를 바탕으로 인수 기준 전체를 점검하라.

1. 실패한 테스트가 있으면 원인을 찾아 **구현을 수정**한다. 테스트 파일은 절대 수정하지 마라.
2. 전부 통과하면 `rec-verifier` 서브에이전트를 호출해 추천 품질을 적대적으로 검증한다.
3. 최종적으로 아래 표를 출력한다.

| ID | 기능 | 상태 | 비고 |
|---|---|---|---|
| F1 | 관광지 수집 ≥150건 | | |
| F2 | 가상 유저 ≥50명 | | |
| F3 | 콘텐츠 기반 추천 | | |
| F4 | 협업 필터링 | | |
| F5 | 코스 생성 | | |
| F6 | Streamlit 기동 | | |
| F7 | 배포 | | |

FAIL 이 하나라도 있으면 무엇부터 고쳐야 하는지 우선순위를 제시하라.
